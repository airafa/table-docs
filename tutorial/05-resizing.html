5. Add the draggable separator between modules ​

Step 1: Distinguish resizing from layout drag-and-drop ​

The request calls this a "drag element," but there are two different operations:

  • Separator resizing: pointer movement changes the relative widths of two already-mounted modules. It uses native pointer events and CSS Grid.
  • Layout editor drag-and-drop: moves/adds modules using the starter kit's existing drag data and drop targets. It uses @starterkit/drag-elements.

Do not introduce a DnD library just to resize two columns. The separator needs no payload, sortable list, or drop target. The existing editor's DnD behavior remains in Panel and should not be removed.

Step 2: Name a container and enable resizing in config ​

The tables layout item declares:

json
{
  "name": "tables",
  "resizable": true,
  "className": "container-panel",
  "style": {
    "display": "grid",
    "gridTemplateColumns": "repeat(auto-fit, minmax(min(100%, 420px), 1fr))",
    "flexShrink": 0
  },
  "droppable": true,
  "layoutElementType": "LAYOUT"
}

This object belongs in the root layout's items. It does not replace the rest of the layout or the map containers.

  • name is the key used by module container config.
  • resizable opts into the separator behavior.
  • display: grid lets the panel assign two tracks with a separator between.
  • flexShrink: 0 prevents the outer vertical layout from collapsing this panel.
  • droppable belongs to editor DnD, not resize enablement.

Step 4: Forward the option through Layout ​

Config flags do nothing unless React receives them. Layout looks up the modules assigned to each panel and passes:

jsx
resizable={layout.resizable}
modules={panels[layout.name] || []}

Complete layout renderer ​

jsx
import React from "react";
import { useLayoutContext } from "@starterkit/layout";
import Panel from "./Panel";
import Module from "../Module/Module";

function Layout({ path = [], layout, onPanelClick, onModuleClick }) {
  const layoutContext = useLayoutContext();
  const panels = layoutContext.panels;

  if (Array.isArray(layout)) {
    return layout.map((layoutItem) => {
      return (
        <Layout
          key={layoutItem.uuid}
          path={[...path]}
          layout={layoutItem}
          onPanelClick={onPanelClick}
          onModuleClick={onModuleClick}
        />
      );
    });
  }

  if (layout.layoutElementType === "MODULE") {
    return (
      <Module
        key={layout.uuid}
        uuid={layout.uuid}
        name={layout.config.name}
        path={path.concat(layout.uuid)}
        style={layout.config.style}
        onClick={onModuleClick}
      />
    );
  }

  return (
    <Panel
      uuid={layout.uuid}
      path={[...path]}
      name={layout.name}
      style={layout.style}
      className={`panel ${layout.name}-panel ${layout.className}`}
      modules={panels[layout.name] || []}
      droppable={layout.droppable}
      onlyDropInside={layout.onlyDropInside}
      resizable={layout.resizable}
      onClick={onPanelClick}
      onModuleClick={onModuleClick}
    >
      {layout.items && (
        <Layout
          path={[...path, layout.uuid]}
          layout={layout.items}
          onPanelClick={onPanelClick}
          onModuleClick={onModuleClick}
        />
      )}
    </Panel>
  );
}

export default Layout;

Step 5: Represent a split with three grid tracks ​

The panel starts with split = 50, meaning:

text
left module        separator        right module
50fr               12px             50fr

If the split becomes 25:

text
25fr               12px             75fr

fr divides the space left after the fixed 12px separator. There is a deliberate 25-75% bound: neither module can consume the whole panel. The implementation enables this only when:

jsx
const canResize = resizable && modules.length === 2;

One module does not need a separator. Three modules would need a different resizing design; this implementation does not pretend to support that case.

Step 6: Convert pointer position to a percentage ​

The handler uses the panel's bounding box, subtracts separator width, and accounts for direction:

text
available width = panel width - 12
LTR offset      = pointer X - panel left
RTL offset      = panel right - pointer X
split           = ((offset - 6) / available width) * 100
clamped split   = max(25, min(75, split))

The half-separator offset keeps the handle centered under the pointer.

Do not set React state on every pointer event. Pointermove can arrive much more often than the browser paints. The implementation stores the latest desired split in a ref and schedules at most one CSS update per animation frame. That update changes gridTemplateColumns directly and updates aria-valuenow. React state is committed when the interaction finishes.

The panel still measures its box and direction for pointer moves; the main performance gains are bounded chart counts and avoiding per-move React panel rerenders, not a claim that the handler has zero layout cost.

Step 7: Capture the pointer and clean up correctly ​

On primary-button pointerdown:

  1. Prevent text selection and stop the editor's click/drag propagation.
  2. Capture the pointer on the separator.
  3. Calculate the first split.

Pointer capture keeps the drag active when the cursor leaves the 12px handle. On pointerup or cancellation, apply the last split, cancel a pending frame, commit state, and release capture. Lost capture commits the last pending split as well. The unmount cleanup cancels scheduled animation work.

The separator is not just a mouse target:

  • role="separator" with vertical orientation describes its function.
  • tabIndex={0} makes it keyboard reachable.
  • Left/Right changes split by one percentage point, respecting RTL.
  • Home and End select 25% and 75%.
  • ARIA min/max/current values announce its state.

Complete Panel implementation ​

Create or inspect app/src/components/Layout/Panel.jsx. This is the complete file, including pre-existing editor DnD handlers:

jsx
import { Fragment, useCallback, useEffect, useRef, useState } from "react";
import Module from "../Module/Module";
import { getConfig, createModule } from "@lc/baseplate";
import { getTransferData } from "@starterkit/drag-elements";
import { selectDevMode } from "../../store/slices/modules/selectors";
import {
  overElementPosition,
  getDroppableAreaPosition,
  addToPosition,
} from "./utlis";
import { useSelector } from "react-redux";
import {
  addLayout,
  addLayoutAfter,
  addLayoutBefore,
  useLayoutContext,
  findLayoutItem
} from "@starterkit/layout";

function Panel({
  uuid,
  name,
  path,
  modules,
  className,
  droppable,
  onlyDropInside,
  resizable,
  onClick,
  onModuleClick,
  children,
  ...rest
}) {
  const refPanel = useRef();
  const [dragOverPosition, setDragOverPosition] = useState(undefined);
  const [split, setSplit] = useState(50);
  const resizeFrame = useRef(0);
  const pendingSplit = useRef(50);
  useEffect(() => () => cancelAnimationFrame(resizeFrame.current), []);
  const canResize = resizable && modules.length === 2;
  const updateSplit = (value) => setSplit(Math.max(25, Math.min(75, value)));
  const handleResize = (event) => {
    const panel = refPanel.current;
    const bounds = panel.getBoundingClientRect();
    const availableWidth = bounds.width - 12;
    if (availableWidth <= 0) return;
    const rtl = getComputedStyle(panel).direction === "rtl";
    const offset = rtl ? bounds.right - event.clientX : event.clientX - bounds.left;
    pendingSplit.current = Math.max(25, Math.min(75, ((offset - 6) / availableWidth) * 100));
    if (!resizeFrame.current) resizeFrame.current = requestAnimationFrame(() => {
      resizeFrame.current = 0;
      panel.style.gridTemplateColumns = `${pendingSplit.current}fr 12px ${100 - pendingSplit.current}fr`;
      panel.querySelector('.panel-resize-divider').setAttribute('aria-valuenow', Math.round(pendingSplit.current));
    });
  };
  const finishResize = (event) => {
    if (!event.currentTarget.hasPointerCapture(event.pointerId)) return;
    cancelAnimationFrame(resizeFrame.current);
    resizeFrame.current = 0;
    refPanel.current.style.gridTemplateColumns = `${pendingSplit.current}fr 12px ${100 - pendingSplit.current}fr`;
    event.currentTarget.setAttribute('aria-valuenow', Math.round(pendingSplit.current));
    updateSplit(pendingSplit.current);
    event.currentTarget.releasePointerCapture(event.pointerId);
  };
  const layoutContext = useLayoutContext();
  const layout = layoutContext.layout;
  const devMode = useSelector(selectDevMode);

  const handlePanelClick = (event) => {
    if (!devMode) return;

    const panelPath = path.concat(uuid);
    const layoutItem = findLayoutItem(layout, panelPath.slice(1));
    const isDroppable = layoutItem?.droppable;

    if (!isDroppable) return;

    onClick(event, panelPath, layoutItem);
  };

  const handleDragOver = useCallback((event) => {
    const { current } = refPanel;
    const parentFlexDirection = current.parentNode.style.flexDirection;
    const overCurrentPosition = overElementPosition(
      current,
      event.clientX,
      event.clientY
    );
    const { elementType } = getTransferData(event);
    const dragOverPosition = onlyDropInside
      ? "middle"
      : getDroppableAreaPosition(
          parentFlexDirection,
          overCurrentPosition,
          elementType
        );

    setDragOverPosition(dragOverPosition);

    event.preventDefault();
    event.stopPropagation();
  });

  const handleDragLeave = (event) => {
    setDragOverPosition(undefined);

    event.preventDefault();
    event.stopPropagation();
  };

  const handleDrop = useCallback((event) => {
    event.stopPropagation();

    const { current } = refPanel;
    const modules = getConfig("modules");
    const { elementName, elementType, metadata } = getTransferData(event);

    setDragOverPosition(undefined);

    if (elementType === "module") {
      const module = modules[elementName];

      if (!module) return;

      createModule(elementName, {
        container: path.concat(uuid)
      });
    }

    if (elementType === "layout") {
      const parentFlexDirection = current.parentNode.style.flexDirection;
      const dragOverPosition = onlyDropInside
        ? "middle"
        : overElementPosition(current, event.clientX, event.clientY);
      const position = addToPosition(
        parentFlexDirection,
        dragOverPosition,
        elementType
      );



      const newLayoutItem = {
        className: "container-panel",
        style: {
          display: "flex",
          flexDirection: "row",
          flex: "1",
        },
        droppable: true,
        layoutElementType: 'LAYOUT'
      };

      if (position === "middle") addLayout(path.concat(uuid), newLayoutItem);
      if (position === "before") addLayoutBefore(path, uuid, newLayoutItem);
      if (position === "after") addLayoutAfter(path, uuid, newLayoutItem);
    }
  });

  const dropProps = droppable
    ? {
        onDrop: handleDrop,
        onDragOver: handleDragOver,
        onDragLeave: handleDragLeave,
      }
    : {};
  const panelClassName = `${className} ${
    dragOverPosition ? "drag-over-" + dragOverPosition : ""
  }`;

  return (
    <div
      ref={refPanel}
      className={panelClassName}
      {...rest}
      style={canResize ? { ...rest.style, gridTemplateColumns: `${split}fr 12px ${100 - split}fr` } : rest.style}
      data-resizable={canResize || undefined}
      {...dropProps}
      onClick={handlePanelClick}
    >
      {children}
      {modules.map((module, moduleIndex) => {
        return (
          <Fragment key={module.uuid}>
          {canResize && moduleIndex === 1 && (
            <div
              className="panel-resize-divider"
              role="separator"
              aria-label="Table widths"
              aria-orientation="vertical"
              aria-valuemin={25}
              aria-valuemax={75}
              aria-valuenow={Math.round(split)}
              tabIndex={0}
              title="Resize tables"
              onClick={event => event.stopPropagation()}
              onPointerDown={event => {
                if (event.button !== 0) return;
                event.preventDefault();
                event.stopPropagation();
                event.currentTarget.setPointerCapture(event.pointerId);
                handleResize(event);
              }}
              onPointerMove={event => {
                if (event.currentTarget.hasPointerCapture(event.pointerId)) handleResize(event);
              }}
              onPointerUp={finishResize}
              onPointerCancel={finishResize}
              onLostPointerCapture={() => updateSplit(pendingSplit.current)}
              onKeyDown={event => {
                const rtl = getComputedStyle(refPanel.current).direction === "rtl";
                if (event.key === "Home") updateSplit(25);
                else if (event.key === "End") updateSplit(75);
                else if (event.key === "ArrowLeft") updateSplit(split + (rtl ? 1 : -1));
                else if (event.key === "ArrowRight") updateSplit(split + (rtl ? -1 : 1));
                else return;
                event.preventDefault();
                event.stopPropagation();
              }}
            />
          )}
          <Module
            key={module.uuid}
            uuid={module.uuid}
            name={module.config.name}
            path={path.concat(module.uuid)}
            style={module.config.style}
            onClick={onModuleClick}
          />
          </Fragment>
        );
      })}
    </div>
  );
}

export default Panel;

Preserve editor integration

The getTransferData, handleDrop, and droppable props serve layout editing. They are not needed to calculate the split, but deleting them would break an existing feature. Merge resize changes into the real panel rather than replacing it with a standalone demo container.
