6. Fill the timeline column and resize its canvases ​

Step 1: Follow width from the outside inward ​

Changing the separator only changes the module host's width. Every layer below it must allow the new size to reach the chart:

text
panel grid track
  -> web-module (min-width: 0)
    -> table demo section (min-width: 0)
      -> lc-gantt.gantt-demo (min-width: 0)
        -> .ds-table-scroll (overflow: auto)
          -> table (width: 100%)
            -> ordinary columns: content width
            -> final timeline column: remaining width
              -> header/row lc-gantt: width: 100%
                -> library ResizeObserver updates canvas dimensions

If any layer fixes the chart at 260px, a wider panel leaves unused space. If a canvas's old intrinsic width forces its parent wider, a shrinking panel can become stuck at its previous size. Both problems need CSS sizing rules, not new date calculations.

Step 2: Start with the shared table stylesheet ​

Complete base table CSS ​

Create or inspect packages/design-system/src/table.css:

css
.table-poc-module { min-width: 0; padding: 16px; color: #20272a; background: #fff; font-family: inherit; }
.table-poc-module h2 { color: #20272a; font-size: 18px; margin: 0 0 12px; }
.table-poc-toolbar { display: flex; align-items: center; flex-wrap: wrap; gap: 12px; margin-bottom: 12px; }
.table-poc-toolbar button, .table-poc-toolbar select { padding: 6px 10px; }
.table-poc-metrics { display: block; margin-top: 10px; font-size: 13px; }
.ds-table-scroll { overflow: auto; max-height: 320px; }
.ds-table { width: 100%; border-collapse: collapse; font-size: 14px; text-align: start; }
.ds-table th, .ds-table td { padding: 8px 12px; border-bottom: 1px solid #dce2e3; white-space: nowrap; text-align: start; }
.ds-table th { position: sticky; top: 0; background: #edf3f1; }
.ds-table th button { color: inherit; font: inherit; font-weight: 600; background: transparent; border: 0; cursor: pointer; }
.ds-table tbody tr:nth-child(even) { background: #f7f9fa; }

Important details:

  • The scroll container has a 320px maximum height.
  • The table fills its container with width: 100%.
  • Cells do not wrap, keeping fixed-height row windowing valid.
  • The header is sticky at top: 0.
  • Cell padding is 8px vertically and 12px horizontally.

Do not silently change these numbers without checking the 49px row contract.

Step 3: Give ordinary columns their content width ​

The Gantt-specific stylesheet scopes its overrides to .gantt-demo:

css
.gantt-demo .ds-table th:not(:last-child),
.gantt-demo .ds-table td:not(:last-child) {
  width: 1%;
}

.gantt-demo .ds-table th:last-child,
.gantt-demo .ds-table td:last-child {
  width: 100%;
}

These are hints to the browser's automatic table layout, not a sum of rigid percentages. The first columns shrink to their nonwrapping content. The final column receives the remaining width.

Timeline must remain the last column

The current selectors intentionally use :last-child. If you append an Actions column after Timeline, these rules will make Actions the expanding column. Keep Timeline last or update the renderer and selectors to identify the timeline column explicitly. Do not copy these selectors and then change the column order without adjusting them.

Step 4: Make the chart fit the cell, not size the cell ​

css
.gantt-header,
.gantt-cell {
  display: block;
  width: 100%;
  min-width: 160px;
  contain: inline-size;
}

Explain each declaration:

DeclarationWhy it matters
display: blockGives the chart a regular measurable width
width: 100%Header and rows fill their respective cell content boxes
min-width: 160pxKeeps a narrow timeline readable instead of collapsing
contain: inline-sizePrevents inner canvas widths from determining the parent's preferred inline size

When the panel is too narrow for the ordinary columns plus the minimum chart width, the table scrolls horizontally. It does not compress the chart to zero or force the entire app wider.

The Timeline child also has:

tsx
<lc-gantt-timeline height={32} style={{ width: '100%' }}>
  <lc-graph-label-element ref={configureLabels} />
</lc-gantt-timeline>

That explicit inline width overrides the package's initial measured-width style, which can otherwise start at zero and stay there.

Step 5: Keep header and rows on the same scale ​

A date-to-pixel coordinate is determined by:

text
pixel = chart width * (date - domain start) / (domain end - domain start)

This simplified formula applies because distortion is zero. Equal date domains alone are not enough: unequal header/row widths still produce different pixels.

The implementation keeps:

  • The same date domain from React context.
  • The same adaptive stepInterval.
  • The same available cell content width.
  • Zero distortion in wrapper, header, and row charts.
  • Header and body cells in the same table column.

The focus pointer is a header-only marker. It does not change the linear scale or require row updates on pointer movement.

Step 6: Let native resize observers repaint the charts ​

@lc/graphs observes its element sizes and updates canvas dimensions. Do not merely stretch an old bitmap with CSS: that could blur it and leave hit-testing/date coordinates wrong.

The header's own ResizeObserver has a narrower purpose: it keys the summary by its measured width and domain end:

tsx
<lc-gantt-summary
  key={`${width}-${domain[1].getTime()}`}
  height={24}
  style={{ height: 48 }}
>
  {/* BinPoint and mouse actions */}
</lc-gantt-summary>

The package can retain obsolete bin drawings after width changes alter D3's generated bin count. Recreating only Summary clears those drawings. Do not key every row/chart by random values or by the dataset revision; that would defeat stable identity and make every refresh expensive.

Step 7: Keep all toolbar blocks in one row ​

The title, record controls, and visible-days controls share a flex row with flex-wrap: nowrap and overflow-x: auto. Nested control groups do not shrink. On narrow panels, scroll the toolbar horizontally to reach the remaining controls.

Long click-feedback text is visually truncated, but its full value remains in the live status node.

Step 8: Check the real geometry ​

For a selected record, the chart's expected width is:

text
timeline content width =
  table width
  - sum of ordinary column box widths
  - timeline cell left/right padding

The browser check uses 24px for the two 12px paddings. It verifies both canvas dimensions and date-to-pixel coordinates, not only a screenshot.

You can inspect a chart in browser DevTools:

js
const section = document.querySelector('[data-table-version="v9.3.1"]');
const header = section.querySelector('.gantt-header');
const row = section.querySelector('.gantt-cell');
const date = new Date('2026-10-10T00:00:00Z');

console.table({
  headerWidth: header.getBoundingClientRect().width,
  rowWidth: row.getBoundingClientRect().width,
  headerPixel: header.getPixelByDate(date),
  rowPixel: row.getPixelByDate(date),
});

Checkpoint: headerWidth and rowWidth match, and headerPixel and rowPixel match (allowing subpixel rounding). Drag the separator and run the inspection again: widths should change while the date coordinates remain equal.
